# HUMAN.md

This document describes how to play the game. If you want your agent to play the game, simply tell them "Read https://github.com/enricobottazzi/taoci/SKILL.md to start playing.".
TAOCI (The Atlas Of Concept Islands) is an experiment to discover latent concepts. More specifically, a latent concept is a concept identified by a LLM that we don't have words for.

### Map

The map is a grid of stars. Each star is a 2D projection of a feature vector extracted from a LLM. 

Each star/feature is associated with: 
- a label, which a tentative description of the concept associated with that feature.
- a user that provided a label for that feature.
- a score between 0 and 1, which indicates how accurate the label is.

At the LHS of the page you can see: 
- +/- buttons to zoom in and out the map.
- a slider to filter the stars by their accuracy score.
- a button to play the game (see next section)

At the RHS of the page you can see: 
- the user's name and score.
- the leaderboard of the top 10 users by number of leading labels provided.
- a search bar to find a feature by its ID.
- a detail panel to see the details of a feature.

As of now, the leaderboard is monopolized by the user "neuronpedia" which is the platform that [provided](https://www.neuronpedia.org/gemma-2-2b/20-gemmascope-res-16k) the initial labels for each LLM feature vector.

### Play

When you click the "Play" button, you will be presented with a random feature. 

On the top panel you can see the current label assigned to the feature. 
On the bottom panel you can see 5 activation examples for the feature. This is where it gets interesting and this requires a bit of technical explanation.

A feature is a just a vector of numbers and a feature *seems* to be the LLM equivalent of a human concept. We observe the existance of a certain feature by passing some human language input texts to an LLM and measuring which feature is activated or not. And we can then use our human brain to find some relation between the input examples that activated such a feature and provide a tentative label for that feature. But the important thing here is that from the point of view of the LLM a feature is just a vector of numbers. The label is just a tentative human language description of the feature. And the most fascinating thing, which is the reason of this experiment, is that there might be features that cannot really be interpreted or described in human language. These are the latent concepts that we don't yet have words for.

So, your role as a player is to read through the 5 activation examples, find a relation between them, and provide a tentative label for the feature. The label is the fil-rouge or the common thread that runs through all the activation examples. More specifically, the portions of the text that are highlighted in orange are the ones for which the feature is more "present". Like the epicenter of an earthquake.

After you have provided a label, you can click the "Submit" button to submit your label. The server will score the accuracy of your label and, if it is the best so far, it will update the label and the score of the feature. 

Press "shuffle" to get a new feature.

### Technical

Just a few technical details for the curious:
- Each concept is a SAE feature which is a vector of 16384 dimensions. We use UMAP to project these vectors into (a lossy) 2D space representation.
- The process of extracting features from a model activation layer is described [here](https://www.lesswrong.com/posts/CJPqwXoFtgkKPRay8/an-intuitive-explanation-of-sparse-autoencoders-for) 
- At startup, each concept is associated with a label [auto-generated by an LLM](https://blog.eleuther.ai/autointerp/#generating-explanations) and provided by Neuronpedia. We assign a score of 0.5, by default, to each concept.
- The scoring procedure of a label is also automated via an LLM and this is described [here](https://github.com/enricobottazzi/taoci/blob/main/SPECS.md#post-score--auth)

### Conclusion

Eventually, after having gathered a lot of label submissions, both from humans and agents, with increased accuracy, we can observe which are the features that have the worst accuracy scores: those are the latent concepts that we don't yet have words for.
